# Anubis Lua Decompiler Bot

بوت ديسكورد لفك تشفير ملفات Lua المشفرة.

## المتطلبات
- Python 3.8+
- Java Runtime Environment (JRE)
- discord.py
- unluac.jar (يتم تضمينه في المشروع)

## طريقة الاستخدام
1. قم بإرسال ملف `.lua` أو `.luac` في الروم المخصص
2. سيقوم البوت بفك تشفير الملف
3. سيتم إرسال الملف المفكك باسم `Anubis.lua`

## التثبيت
1. قم بتثبيت المتطلبات:
```bash
pip install -r requirements.txt
```
2. قم بتعديل ملف `config.py` ووضع توكن البوت و ID الروم
3. شغل البوت:
```bash
python bot.py
```
